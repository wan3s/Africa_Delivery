# Task 3. Нефункциональные требования и стратегия доступности

**Ключевые цифры:** бюджет ошибок приёма заказа — 40 мин за 28 дней; порог RPN для обязательных мер — 100 (превышен у 7 позиций из 12); обнаружение нарушения SLO — не более 5 минут; бюджет на наблюдаемость — \$200/мес.

**Три верхних риска до запуска:** дубли платёжных колбэков (RPN 400), отправка без согласия (320), недоступность платёжного провайдера (192).
