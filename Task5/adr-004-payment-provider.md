# ADR-004: Выбор платёжного провайдера

| | |
| --- | --- |
| **Статус** | Предложено |
| **Дата** | 02.09.2026 |
| **Владелец решения** | CFO — по комиссии и юнит-экономике; CEO — по договорам с провайдерами |
| **Участники** | CTO, команда разработки, внешний юрист |
| **Противоречие-источник** | C-03 (CTO предлагает работать с провайдерами напрямую против срока и лицензионных требований) |

## Контекст

Приём платежей в любой из трёх стран требует лицензии либо договора с лицензированным провайдером; получение собственной лицензии в заявленные сроки нереалистично (арт. 3). CFO ограничивает стоимость приёма платежей 2,5% GMV со всеми конвертациями (арт. 6). CTO предлагает отказаться от агрегаторов и интегрироваться с M-Pesa и Flutterwave напрямую, чтобы не платить процент посреднику (арт. 5).

Банковские карты использует около 20% рынка, доминируют мобильные деньги: M-Pesa в Кении, переводы и USSD-платежи в Нигерии.

## Рассмотренные варианты

| Вариант | Трудоёмкость | Комиссия | Оценка |
| --- | --- | --- | --- |
| Один агрегатор на все страны | 2 недели | Комиссия провайдера + 0,3–0,5% посреднику | Дороже в обороте: при GMV Года 1 надбавка составляет 22–37 тыс. USD. Отклонён |
| Прямые интеграции со всеми провайдерами | ~9 недель (3 × 3 недели) | Базовая комиссия каждого провайдера | Занимает весь буфер проекта; экономия 20–35 тыс. USD не покрывает стоимость разработки и поддержки в первый год. Отклонён на старте |
| **Прямая интеграция с провайдером-лидером в каждой стране, один резервный** | **4 недели** | **Базовая комиссия** | Компромисс: платим базовую комиссию там, где идёт основной оборот, и не строим оркестратор на три страны. **Выбран** |
| Собственная лицензия | 6–12 месяцев | Минимальная | Невозможно к 15 октября (арт. 3). Отклонён |

## Решение

| Страна | Основной провайдер | Методы | Резерв | Когда |
| --- | --- | --- | --- | --- |
| Нигерия | Flutterwave | Переводы, USSD-платежи, карты | Paystack — переключение при недоступности основного дольше 5 мин | MVP |
| Кения | M-Pesa (Safaricom Daraja) | Мобильные деньги | Альтернативы нет: при отказе заказ принимается в очередь | MVP |
| Кения | Flutterwave | Карты | — | MVP |
| ЮАР | Выбирается на КТ3 | Карты, мгновенные переводы | — | 6 месяцев |

Наличные при получении обрабатывает логистический партнёр и перечисляет инкассированные суммы — отдельного платёжного контура не требуется.

Маршрутизация метода и провайдера задаётся конфигурацией, а не кодом: добавление провайдера в новой стране не меняет модуль `payments`.

## Проверка ограничения 2,5% GMV

| Страна | Метод | Доля метода | Комиссия | Вклад |
| --- | --- | --- | --- | --- |
| Нигерия (60% GMV) | Переводы и USSD | 80% | 1,4% | 1,12% |
| | Карты | 5% | 3,8% | 0,19% |
| | Наличные при получении | 15% | 1,5% (инкассация партнёра) | 0,23% |
| | **Итого по стране** | | | **1,54%** |
| Кения (40% GMV) | M-Pesa | 85% | 1,5% | 1,28% |
| | Карты | 15% | 2,9% | 0,44% |
| | **Итого по стране** | | | **1,72%** |
| **Средневзвешенная по обороту** | | | | **1,61%** |
| Конвертация валют и переводы продавцам | | | | +0,5% |
| **Итого** | | | | **2,11% — в пределах ограничения** |

Запас до порога — 0,39 процентного пункта. Он расходуется при росте доли карт и международных платежей, поэтому доля методов оплаты выносится на ежемесячный отчёт CFO (NFR-OPS-05). При приближении к 2,4% включается маршрутизация на более дешёвый метод: например, подсказка платить через мобильные деньги вместо карты.

## Позиция CTO

Аргумент «агрегаторы вечно берут процент с каждой транзакции» принят: агрегатор поверх провайдеров отклонён, мы платим базовую комиссию. Не принято требование интегрироваться напрямую со всеми провайдерами сразу: это девять недель при восьми доступных, а экономия меньше стоимости работы. Прямые интеграции добавляются по одной, когда оборот в стране оправдывает разработку: порог — 1 млн USD GMV в стране в месяц, при котором 0,3 процентного пункта комиссии окупают три недели работы за квартал.

## Границы решения

| Отложено | Триггер возврата |
| --- | --- |
| Прямая интеграция с дополнительными провайдерами | GMV страны выше 1 млн USD в месяц |
| Собственная платёжная лицензия | Выход в третью страну сверх плана либо требование регулятора |
| Кошелёк и переводы между пользователями | Наличие лицензии на электронные деньги |
| Рассрочка и кредитный скоринг | Накопленная история платежей за 12 месяцев |

## Последствия

**Положительные.** Запуск платежей укладывается в 4 недели. Комиссия 2,11% оставляет запас до порога CFO. В Нигерии есть резервный провайдер, то есть отказ Flutterwave не останавливает продажи.

**Отрицательные.** В Кении альтернативы M-Pesa нет: её недоступность останавливает оплату, и единственная защита — приём заказа в очередь (FM-03). Два разных провайдера означают две схемы сверки и два формата колбэков — сверка усложняется, а это место с наивысшим риском в FMEA (FM-01). Комиссии могут быть пересмотрены провайдером в одностороннем порядке; договор должен содержать уведомление за 30 дней, иначе юнит-экономика меняется без нашего участия.

**Риски и меры.** Превышение 2,5% — ежемесячный отчёт и переключение маршрутизации. Задержка подключения к M-Pesa (процедура подключения к Daraja занимает недели) — заявка подаётся на первой неделе, до готовности интеграции; это отдельный риск в `risk-register.md`.

## Обратимость

Смена провайдера в стране — изменение конфигурации маршрутизации и одна новая интеграция, около 3 недель. Модель данных не зависит от провайдера: хранятся идентификатор операции и статус, а не его внутренние структуры. Переход на прямые интеграции возможен без изменения интерфейса модуля `payments`.

## Assumptions

- Ставки комиссий и доли методов оплаты — оценки по публичным тарифам и описанию рынка из условия; уточняются коммерческими предложениями провайдеров до подписания договоров.
- Доли GMV по странам (60% Нигерия, 40% Кения) приняты по размеру рынков; при ином распределении средневзвешенная комиссия меняется в пределах 1,5–1,8%.
